# Chocolete-Sales-Dashboard
Power BI dashboard analyzing chocolate sales, orders, countries, and monthly sales trends.

## Dashboard Overview

The dashboard provides an interactive view of:

- Total Boxes Sold
- Total Order Cards
- Total Sales
- Sales by Country
- Monthly Sales Trends
- Order Status Analysis

## Tools & Technologies

- Power BI
- Microsoft Excel
- Data Visualization
- Data Analysis

## Dashboard Preview

![Chocolate Sales Dashboard](./dashboard-preview.png)

## Key Insights

The dashboard helps identify:

- Countries generating the highest sales.
- Overall sales and order performance.
- Monthly changes in sales.
- Distribution of orders by status.
